# Trabalho de Redes - Quake

Descrição do projeto aq

## Como rodar
- Rode o programa `server.py`, e escolha uma porta para criar o servidor TCP/UDP
- Abra um cliente (jogo) do Godot, e conecte via menu inicial
- Depois de todos jogadores conectados, inicie o jogo

## Referências
- Material do laboratório de Servidor Web, da disciplina de Redes
- Documentação das bibliotecas de Python [Threading](https://docs.python.org/3/library/threading.html#) e [Socket](https://docs.python.org/3/library/socket.html#)
- Documentação das classes em GDScript [PacketPeerUDP](https://docs.godotengine.org/en/stable/classes/class_packetpeerudp.html) e [StreamPeerTCP](https://docs.godotengine.org/en/stable/classes/class_streampeertcp.html)
